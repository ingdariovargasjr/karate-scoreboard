# Karate Scoreboard AKT

Aplicación de escritorio para administrar competencias de karate (kata y kumite) y mostrar el marcador.

## Desarrollo local

Requiere Node.js y npm.

```sh
npm ci
npm start
```

`npm start` genera `css/output.css` y abre la aplicación en Electron. Para generar un paquete de escritorio, usa `npm run make`.
