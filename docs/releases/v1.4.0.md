# Karate Scoreboard AKT v1.4.0

## Resumen

Primera entrega funcional completa del marcador de observaciones: kumite, TV kumite, kata, cronómetros y flujo de votos.

## Incluye

- Operador de kumite con AO azul a la izquierda y AKA rojo a la derecha.
- Puntuación `+3`, `+2`, `+1` y `-1`, Senshu por competidor y penalizaciones compactas.
- Shikkaku con victoria inmediata del rival, exclusión de inscripciones seleccionadas y corrección antes de nuevos resultados.
- Cronómetro médico independiente de tres minutos, sincronizado con TV.
- TV de kumite con indicadores C1/C2/C3/HC/H y colores de reloj por estado.
- Kata con cronómetros de 35 segundos y 5 minutos.
- Configuración de 5 o 7 jueces para gráficas nuevas.
- Dos filas de notas AKA/AO en operador, votos por juez y mayoría como criterio de ganador.
- Desempate por corrección de cualquier nota cuando los votos empatan.
- TV de kata sin notas por juez ni sumas: publica únicamente votos totales y ganador cuando corresponde.
- Persistencia de borradores de notas y votos en las gráficas.
- Instalador Windows Squirrel con icono personalizado de Karate Scoreboard AKT.

## Instalación en Windows

1. Descarga `Karate Scoreboard AKT-1.4.0 Setup.exe` desde los archivos de este release.
2. Ejecuta el instalador y confirma la instalación para el usuario de Windows.
3. Abre **Karate Scoreboard AKT** desde el menú Inicio o el acceso directo creado.

También se distribuye una carpeta portable `Karate Scoreboard AKT-win32-x64` para ejecutar sin instalar. La opción recomendada es el `Setup.exe`, porque crea la instalación y los accesos directos.

> El instalador no está firmado digitalmente. Windows puede mostrar SmartScreen; verifica que el archivo provenga de este release antes de continuar.

## Validación de esta entrega

- `npm run build:css`
- `npm run make`
- Verificación manual en navegador local de operador, TV, votos, empate y persistencia.
- Verificación de lanzamiento con `npm start`.

## Limitaciones conocidas

- La recepción inalámbrica de notas desde jueces todavía no está implementada.
- La creación de eventos necesita corrección independiente antes de considerarse funcional.
- `npm test` continúa siendo un placeholder; no hay suite automática, lint ni typecheck configurados.
- La exportación JSON no incluye eventos; respalda competidores y gráficas.
- El instalador no incluye firma de código.
