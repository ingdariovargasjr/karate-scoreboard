# Karate Scoreboard AKT v1.4.1

## Resumen

Versión de corrección posterior a v1.4.0. Se corrige el flujo de empate de jueces en kata y se restaura el diseño TV anterior al intento de resize.

## Guía de fixes

### Empate de calificación de un juez

- Una misma calificación para AKA y AO ya no se convierte automáticamente en un voto para ambos.
- Las dos celdas empatadas se resaltan con borde dorado, fondo amarillo tenue y parpadeo de alerta.
- Aparece una notificación en la esquina superior derecha con el mensaje: **«Este juez dio la misma calificación. Por favor corregir»**.
- La notificación identifica el número del juez y se puede cerrar con `X` para editar las notas.
- Mientras exista el empate, se bloquean los votos y la adjudicación del ganador.

### Marcador TV

- Se restauró el diseño anterior de las vistas TV de kata y kumite.
- Se retiraron las reglas experimentales de resize que estaban produciendo una escala incorrecta en algunas pantallas.

## Instalación en Windows

1. Descarga `Karate Scoreboard AKT-1.4.1 Setup.exe` desde los archivos de este release.
2. Ejecuta el instalador y confirma la instalación.
3. Abre la aplicación desde el menú Inicio o el acceso directo.

También se incluye una versión portable en ZIP para ejecutar sin instalación.

> El instalador no está firmado digitalmente. Windows puede mostrar SmartScreen; verifica que el archivo provenga de este release oficial.

## Validación

- `npm run build:css`
- `npm run make`
- Verificación de sintaxis JavaScript inline.
- `git diff --check`.
