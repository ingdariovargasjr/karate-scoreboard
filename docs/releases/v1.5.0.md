# Karate Scoreboard AKT v1.5.0

## Resumen

Esta entrega añade gestión local de eventos con respaldo transferible, resultados automáticos de gráficas, exportación PDF horizontal, controles Kiken y temporizadores/avisos del scoreboard actualizados. También incorpora las categorías de peso de Olimpiada Nacional con límites verificados en cada rama.

## Cambios

- Creación y administración de eventos locales; el respaldo JSON incluye eventos, nombres, logo, competidores, gráficas, resultados y progreso parcial.
- Exportación de gráficas como PDF 16:9 de una página a partir del HTML renderizado.
- Asignación del podio al terminar la final: campeón, subcampeón y dos terceros lugares calculados desde las semifinales.
- Botones Kiken en kata y kumite que entregan el encuentro al oponente.
- El reloj detenido se oculta del scoreboard. En kata por equipo, 35 segundos transiciona automáticamente a 5 minutos.
- Anuncios de puntos de kumite a pantalla completa durante 1.5 segundos con fondo AKA/AO e iconos SVG de técnica.
- Categorías de Olimpiada Nacional para 14–15, 16–17 y 18–20 años. Los límites `-X kg` incluyen `X.00 kg`; desde `X.01 kg` se pasa al siguiente límite o a `+X kg`.

## Instalación en Windows

1. Descarga `Karate Scoreboard AKT-1.5.0 Setup.exe` desde los archivos de este release.
2. Ejecuta el instalador y confirma la instalación.
3. Abre **Karate Scoreboard AKT** desde el menú Inicio o el acceso directo.

También están disponibles `Karate.Scoreboard.AKT-1.5.0-portable-win32-x64.zip`, `karate-scoreboard-akt-1.5.0-full.nupkg`, `RELEASES` y el archivo de checksums. El instalador no está firmado digitalmente; Windows puede mostrar SmartScreen.

## Validación

- `npm test`: 24 casos pasaron, con los límites `X.00`/`X.01` de todas las categorías y entradas inválidas.
- Interfaz Microsoft Edge: 14–15 femenil, 47.00 kg → `-47kg`; 47.01 kg → `-54kg`. No se registró competidor.
- `git diff --check`.
- `npm run make` completó en Windows x64 y generó el instalador Squirrel, el paquete completo y el índice de actualización.
- Se creó un ZIP portable desde la carpeta de aplicación generada por Forge.
