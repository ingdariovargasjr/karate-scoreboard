# Karate Scoreboard AKT v1.4.3

## Resumen

Esta versión permite configurar en local el nombre del torneo y verlo en las vistas del operador y en las pantallas de Kata/Kumite TV. Conserva el rediseño de marcadores incluido en v1.4.2 y no modifica reglas deportivas, puntuación ni temporizadores.

## Novedades

- En **ADMIN**, escribe el nombre en **Nombre del torneo** y pulsa **GUARDAR NOMBRE**.
- El nombre se guarda en el almacenamiento local del equipo y se conserva al volver a abrir la aplicación.
- Se muestra en la navegación, Registro/Admin, operador de Kata y Kumite, vista de juez y marcadores TV de Kata y Kumite.
- Si aún no se ha configurado, las pantallas indican **CONFIGURAR TORNEO** en lugar de mostrar “Torneo Local”.
- El nombre se sincroniza con las ventanas TV abiertas.

## Datos y SQL

No se requiere SQL ni una migración. El nombre del torneo se guarda localmente y no altera el esquema ni los datos de competidores y gráficas.

## Instalación en Windows

1. Descarga `Karate.Scoreboard.AKT-1.4.3.Setup.exe` desde los archivos de este release.
2. Ejecuta el instalador y confirma la instalación.
3. Abre **Karate Scoreboard AKT** desde el menú Inicio o el acceso directo.

También se publica `Karate.Scoreboard.AKT-1.4.3-portable-win32-x64.zip` como versión portable. El instalador no está firmado digitalmente; Windows puede mostrar SmartScreen. Verifica que los archivos provengan del release oficial.

## Validación

- `npm run build:css`
- `npm run make` en Windows x64
- Verificación de sintaxis del módulo JavaScript inline.
- `git diff --check`.
- No hay suite automatizada configurada (`npm test` es un placeholder).
