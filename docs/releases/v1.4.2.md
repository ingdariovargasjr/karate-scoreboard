# Karate Scoreboard AKT v1.4.2

## Resumen

Actualización de la interfaz de Kata y Kumite, enfocada en que el público pueda leer la información del encuentro y el estado del marcador a distancia. No cambia las reglas deportivas, la puntuación ni los temporizadores.

## Novedades

### Kata

- Se rediseñó Kata TV para mostrar con mayor claridad tatami, categoría/división, competidor, municipio, kata y logo del torneo.
- Se actualizó el panel del operador de Kata conservando su estilo mate y los controles existentes.
- El logo puede cargarse, cambiarse o quitarse desde **Registro/Admin → Logo de Kata TV**.

### Kumite

- Se rediseñó Kumite TV con fondo oscuro enmarcado y una jerarquía visual de AKA rojo y AO azul.
- Se muestran datos de gráfica como tatami, categoría/división, peso, ronda y número de combate.
- El marcador comparte el logo configurado para Kata TV; si no hay uno, utiliza el logo AKT.
- Senshu se identifica con un triángulo verde en la esquina inferior derecha del puntaje correspondiente.
- Las penalizaciones de cada competidor aparecen debajo de los puntajes; las activas se resaltan en amarillo.
- El reloj detenido se muestra blanco, en marcha amarillo y en los últimos 15 segundos rojo.

## Datos y SQL

No se requiere script ni migración SQL para esta versión. La aplicación de escritorio conserva los datos en el almacenamiento local del perfil de Electron y este cambio no modifica su esquema.

## Instalación en Windows

1. Descarga `Karate.Scoreboard.AKT-1.4.2.Setup.exe` desde los archivos de este release.
2. Ejecuta el instalador y confirma la instalación.
3. Abre **Karate Scoreboard AKT** desde el menú Inicio o el acceso directo.

También se publica `Karate.Scoreboard.AKT-1.4.2-portable-win32-x64.zip` como versión portable. El instalador no está firmado digitalmente; Windows puede mostrar SmartScreen. Verifica que los archivos provengan del release oficial.

## Validación
